# ТРИЗ — `triz`

ТРИЗ — теория решения изобретательских задач. Её придумал инженер Генрих Альтшуллер, изучив тысячи изобретений.

Скилл разбирает задачу по шагам: формулирует противоречие, описывает идеальный результат, ищет, что уже есть под рукой, и предлагает несколько решений. Может оценить готовое решение по шкале от 0 до 10. Вызывается командой /triz или сам, когда в задаче есть противоречие.

## Установка

```bash
npx skills@latest add nselihov/skills --skill triz -g
```
