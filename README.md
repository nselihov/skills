# Skills

Скиллы для продуктового дизайна. Работают в Claude Code и других AI-агентах.

## Установка

```bash
npx skills@latest add nselihov/skills -g
```

## ТРИЗ — `triz`

ТРИЗ — теория решения изобретательских задач. Её придумал инженер Генрих Альтшуллер,
изучив тысячи изобретений.

Скилл разбирает задачу по шагам: формулирует противоречие, описывает идеальный
результат, ищет, что уже есть под рукой, и предлагает несколько решений. Может оценить
готовое решение по шкале от 0 до 10. Вызывается командой `/triz` или сам, когда в задаче
есть противоречие.

## English

Skills for product design. They work in Claude Code and other AI agents.

**triz** — TRIZ is the Theory of Inventive Problem Solving. It was created by engineer
Genrich Altshuller, who studied thousands of inventions.

The skill works through a task step by step: it states the contradiction, describes the ideal
result, looks for what is already at hand and suggests several solutions. It can rate an
existing solution on a scale from 0 to 10. Run it with `/triz`, or it starts on its own when
a task contains a contradiction.
